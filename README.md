A clean, modern, and **fully functional** .NET MAUI showcase app – perfect as a starter template or portfolio piece.

Fully responsive • Dark/Light mode ready • Zero text truncation • Beautiful cards • Hot Reload demo

<img src="https://github.com/ethqnit/MauiShowcase/blob/main/showcase.png?raw=true" alt="Screenshot" width="800"/>

## Features

- Single codebase running on **iOS, Android, Windows, macOS**
- Modern Fluent-style UI with proper spacing and safe areas
- Smooth tap counter with accessibility support
- Feature cards with icons and descriptions
- Built with the latest .NET 8 + MAUI best practices (2025)

## Run it yourself (30 seconds)

```bash
git clone https://github.com/kilog/MauiShowcase.git
cd MauiShowcase
dotnet restore
dotnet build
Then press F5 in Visual Studio or use:
Bashdotnet run --project MauiShowcase
Tech Stack

.NET 8
.NET MAUI
XAML + MVVM-ready structure
Fully typed with C# records
GitHub-ready with proper .gitignore
